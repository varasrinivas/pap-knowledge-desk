# Supported browsers and troubleshooting

Use this when the portal behaves oddly: buttons that do nothing, pages that will not load, or letters that will not open. Most problems are fixed by using a supported browser, clearing site data, or allowing pop-ups.

## Supported browsers
- The current version of **Google Chrome** or **Microsoft Edge**.
- Other browsers and older versions are not supported. Some screens may load but buttons, uploads or downloads may fail.
- Keep the browser updated; both update themselves automatically when restarted.

## Procedure: Clear site data after a long session
Use this if the portal has been open for more than 8 hours, or if pages show old information or stop responding.
1. Save any work in progress. In the wizard, click **Save draft**.
2. Close all portal tabs.
3. Open your browser's settings and find the site data or cookies for the portal.
4. Clear the site data for the portal only.
5. Restart the browser.
6. Sign in again from the **Sign in** screen, including **Enter the 6-digit code**.

**What you should see:** **Home** loads with current statuses, and buttons respond normally.

## Procedure: Allow pop-ups so decision letters open
1. Open the request and click the **Decision** tab.
2. Click **Download letter**. If nothing happens, look for the blocked pop-up icon in the address bar.
3. Click the icon and choose to always allow pop-ups from the portal.
4. Click **Download letter** again.

**What you should see:** The letter opens or downloads as a PDF (UI-09).

## Procedure: Check before you report a problem
1. Confirm you are using current Chrome or Edge.
2. Clear site data and sign in again as above.
3. Try the same action once more and note the exact error message.
4. If it still fails, use **Help** > **Contact support** (UI-18). Give the screen, the button you pressed, the error text and the `IR-` number if there is one. Do not include member details.

**What you should see:** Either the problem is gone, or you have the details the Service Desk needs.

## Common errors on this screen
- **"Buttons stopped working after lunch"**: The session has been open a long time. If it has been open over 8 hours, clear site data and sign in again.
- **"Download letter does nothing"**: The pop-up blocker stopped the letter. Allow pop-ups for the portal.
- **"The page layout is broken"**: You are using an unsupported or outdated browser. Switch to current Chrome or Edge.
- **"Everyone in the office has the same problem"**: It may be a known outage. Use **Help** > **Contact support**; the assistant tells you if there is an open incident and when the next update is due.
